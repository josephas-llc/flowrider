## Market Reality Check

### What We Got Wrong Before

The previous version used **additive multiples** (20x + 10x + 5x = 35x), which is not how SaaS valuations work. Investors apply **percentage premiums** to a base multiple.

**Wrong (v3.0):**
```
Base: 20x ARR
+ ZOIX: +10x
+ Billing: +5x
= 35x ARR total  ← THIS IS WRONG
```

**Correct (v3.1):**
```
Base: 5-8x ARR (market median)
× ZOIX premium: +30% (if proven)
× Growth premium: +20% (if >100% YoY)
= 7-12x ARR total  ← THIS IS REALISTIC
```
