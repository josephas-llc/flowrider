## Production Notes

### Screen Recordings Needed:
1. Icosahedron spinning with active sessions
2. Clicking between faces/sessions
3. Provider switching dropdown
4. ZOIX insights panel
5. Cost tracking dashboard
6. Autopilot demo (optional B-roll)

### Music:
- Electronic, slightly dark, building energy
- Think: Trent Reznor meets tech demo
- Royalty-free options: Epidemic Sound, Artlist

### Text Style:
- Bold, sans-serif (Inter or similar)
- White on dark, occasional accent color (cyan/purple)
- Quick cuts, 2-3 seconds max per text overlay

### Recording Tips:
- Use existing autopilot demo feature for smooth recordings
- Dark theme for visual consistency
- Zoom in on key UI elements
- 4K if possible, will look good scaled down
