## RECORDING TIPS

### Screen Recording
- Use OBS or ScreenFlow
- 1920x1080 minimum (4K preferred)
- 60fps for smooth animations
- Hide personal info, bookmarks

### Audio
- Record voiceover separately
- Use a good mic (Blue Yeti or better)
- Record in a quiet room
- Leave 2-second gaps for editing

### App Setup
- Use Demo Mode (pre-populated data)
- Have 5-6 sessions "active" with names
- Pre-load some AI providers as selected
- Have dashboard metrics showing interesting numbers

### Editing
- Cut aggressively (no dead air)
- Add subtle zoom on clicks
- Use transitions sparingly
- Add keyboard shortcut callouts
